# 底图瓦片（未包含在仓库中）

站点默认从本地读取瓦片：

```
tiles/{z}/{x}/{y}.png
```

仓库不包含这些文件，原因：

- 高德瓦片的使用受其服务条款约束，缓存的瓦片不适合随代码公开分发
- 瓦片体积会随缩放级别快速膨胀

两种处理方式：

1. **使用已获授权的瓦片服务**：修改 `assets/config.js` 里的 `tileUrl` 和 `attribution`
2. **自备离线瓦片**：把瓦片放在 `tiles/{z}/{x}/{y}.png`，该目录已被 `.gitignore` 忽略，不会误传

注意坐标系：高德瓦片使用 GCJ-02，与 `assets/data.js` 中的坐标一致。换成 OpenStreetMap 等 WGS-84 底图时，桩位会偏移几百米，需要额外转换。
